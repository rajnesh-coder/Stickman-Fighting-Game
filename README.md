# Stickman-Fighting-Game
A small game with 4 levels where you fight enemies.

You need to have SDL library installed to run this game.
-> to compile the code use the following command.
 g++ main.cpp -o run `pkg-config --cflags --libs sdl3 sdl3-ttf sdl3-image sdl3-mixer`
-> to run it on linux use the command
./run
